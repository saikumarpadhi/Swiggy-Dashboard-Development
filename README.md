# 🍽️ Swiggy Delivery Analytics – Power BI Dashboard

## 🚀 Project Overview

I challenged myself to build a **complete Power BI project from scratch** — including creating a dataset, modeling it, writing DAX, and designing a full dashboard.
This Swiggy-style delivery analytics report helped me learn real business reporting concepts end-to-end.

---

## 📂 Dataset

Since no real data was available, I **generated my own dataset using ChatGPT** with columns like:

* Order Date
* City
* Restaurant Name
* Food Category
* Delivery Time
* Ratings
* Sales
* Delivery Status

This simulated realistic business insights and allowed full analysis inside Power BI.

---

## ⚙️ Challenges Faced

Building this dashboard wasn’t easy — I learned a lot while solving problems like:

* 🔹 Cleaning & transforming raw data in **Power Query**
* 🔹 Handling **Date Hierarchies & Time Intelligence**
* 🔹 Writing **YoY growth and Moving Average calculations in DAX**
* 🔹 Creating **trend indicators using dynamic icons (📈/📉)**
* 🔹 Designing a **clean layout with consistent color theme**
* 🔹 Exporting the report in **HD for sharing**

Every blocker helped me go deeper — and that’s where real learning happened.

---

## 📊 Dashboard Highlights

The Swiggy Dashboard showcases:

* 📈 **Year-on-Year Sales and Profit Trends**
* 🕒 **Average Delivery Time & On-Time Delivery %**
* 🍔 **Category-wise Performance**
* ⭐ KPI cards, slicers, and interactive visuals
* 🧩 Insights that show real patterns behind business behavior

---

## 🧠 Key Learnings

* DAX is not just formulas — **it’s logic + storytelling**
* **Data cleaning takes more time than visualization** (and that’s okay)
* A great dashboard **looks simple even if it is complex internally**
